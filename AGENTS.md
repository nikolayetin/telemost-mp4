# Telemost MP4 - инструкция для ИИ-агента

Этот файл для агента (Claude Code, Codex и другие), которого человек попросил поставить Telemost MP4. Говори с человеком на его языке, коротко и без терминов: он мог ни разу не открывать Терминал.

**Что ты ставишь.** Сторож для macOS: записи звонков программы Яндекс Телемоста для компьютера (webm) сами превращаются в mp4 в той же папке, webm уходит в корзину. Всё работает локально, без сети. Подробнее - `README.md`.

## Порядок

1. **Это Mac?** `uname -s` должен вернуть `Darwin`. Иначе скажи, что пока есть только версия для Mac, и остановись.
2. **Уже стоит?** `launchctl print gui/$(id -u)/local.telemost-mp4 >/dev/null 2>&1 && echo стоит`. Если стоит - это обновление: скажи человеку, что Telemost MP4 уже есть и ты его обновишь. Нынешний выбор про webm: файл `~/Library/Application Support/telemost-mp4/keep-webm` есть - webm остаётся, нет - уходит в корзину.
3. **Репозиторий.** Если его ещё нет на диске: `git clone https://github.com/nikolayetin/telemost-mp4.git ~/telemost-mp4`. Уже есть - `git -C ~/telemost-mp4 pull`. Дальше все команды - из этой папки.
4. **Один вопрос человеку:** после перекодирования убирать webm в корзину или оставлять рядом с mp4? По умолчанию - в корзину (при обновлении - как сейчас).
5. **Предупреди заранее:** во время установки macOS может показать окно, что «Telemost MP4» просит доступ к папке «Документы» (или к той папке, где лежат записи). Нужно нажать «Разрешить», иначе сторож не увидит записи. Если записи лежат не в «Документах», окна может не быть вовсе.
6. **Установка.** `zsh install.sh --trash-webm < /dev/null` или `zsh install.sh --keep-webm < /dev/null` - ключ всегда передавай явно, иначе останется прошлый выбор. Без терминала установщик вопросов не задаёт и сам отвечает «нет». ffmpeg он ищет сам, везде, где тот обычно стоит. Установка прошла, если код выхода 0 и есть строка «✓ Telemost MP4 стоит».
7. **Разбери, что ещё написал установщик:**
   - «→ в папке старых записей: N (… МБ), их не трогаю» - спроси человека, перекодировать ли и их. Да - повтори шаг 6 с `--all` (тот же ключ про webm).
   - «беру стандартную папку …» - установщик не нашёл, куда Телемост пишет записи, и взял «Документы/Телемост». Спроси человека, какая папка стоит в настройках программы Телемоста (раздел «Папки»). Другая - повтори шаг 6 с `--dir "<папка>"`. Папка должна уже существовать: если её нет, пусть человек сделает одну тестовую запись в Телемосте, она её создаст.
   - «! Не нашёл программу Телемоста» - спроси, стоит ли у человека программа Телемоста для компьютера. Telemost MP4 работает только с её записями, записи из браузера он не берёт.
   - «✗ Нужен ffmpeg … https://brew.sh» - нет ни ffmpeg, ни Homebrew. Дай ссылку https://brew.sh, объясни, что после установки Homebrew надо вернуться к тебе, и остановись.
   - «✗ Без ffmpeg не получится: brew install ffmpeg» - Homebrew есть, ffmpeg нет. Спроси разрешения и выполни `brew install ffmpeg`. Если `brew` не находится (Homebrew только что поставили), бери полный путь: `/opt/homebrew/bin/brew` на Mac с Apple Silicon, `/usr/local/bin/brew` на Intel. Потом повтори шаг 6.
   - «✗ Нужны инструменты разработчика Apple» - выполни `xcode-select --install`, попроси человека согласиться в появившемся окне и дождаться конца, потом повтори шаг 6.
   - «✗ Записи идут прямо в …» - в настройках Телемоста записи сохраняются в общую папку («Загрузки», «Документы» и подобные). Попроси человека выбрать в настройках Телемоста отдельную папку для записей и повтори шаг 6.
   - «✗ Терминалу нет доступа к …» - macOS не пускает к папке записей программу, в которой ты работаешь (Терминал, iTerm, Visual Studio Code, Cursor, Codex - смотря где ты запущен). Попроси человека открыть «Системные настройки → Конфиденциальность и безопасность → Файлы и папки» и включить для этой программы нужную папку; если программы там нет - «Полный доступ к диску». После этого программу, возможно, придётся перезапустить. Потом повтори шаг 6.
   - Любая другая строка с «✗» - перескажи её человеку своими словами и предложи, что сделать.
8. **Проверка.**
   - `launchctl print gui/$(id -u)/local.telemost-mp4 >/dev/null 2>&1 && echo загружен`. «загружен» - всё хорошо; если смотришь подробнее, `state = not running` - тоже норма: сторож спит, пока в папке записей ничего не меняется. Нет ответа - установка не дошла до конца, повтори шаг 6 и разбери его вывод.
   - `tail -5 ~/Library/Logs/telemost-mp4.log`. Пусто или только старые строки - норма, пока не было новой записи.
   - Строка «нет доступа» - у «Telemost MP4» нет разрешения. Попроси человека открыть «Системные настройки → Конфиденциальность и безопасность → Файлы и папки → Telemost MP4» и включить папку с записями (если раньше нажали «Не разрешать», macOS сама больше не спросит - только здесь). Потом запусти сторожа заново: `launchctl kickstart gui/$(id -u)/local.telemost-mp4` - и проверь журнал ещё раз.
   - Попроси человека сделать тестовую запись: зайти во встречу в программе Телемоста (можно одному), нажать «Записать на компьютер», подождать секунд 15 и остановить. Примерно через минуту в журнале появится строка «готово … .mp4». Покажи её человеку и скажи, что тестовый mp4 в папке записей можно удалить. Уведомление «Запись готова» приходит от имени «Редактора скриптов».

## Удаление

`zsh install.sh uninstall` из папки репозитория: программа, агент и настройки уходят в корзину, доступ к папке отзывается, записи остаются. ffmpeg остаётся на месте.

## Чего не делать

- Не запускай ничего через `sudo`: установщику права администратора не нужны.
- Не трогай файлы, настройки и журналы Телемоста и сами записи - только `install.sh`.
- Не правь `convert.sh` и `runner.swift` под человека: всё настраивается ключами `install.sh` (`--dir`, `--keep-webm`, `--trash-webm`, `--all`).
