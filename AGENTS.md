# Telemost MP4 - инструкция для ИИ-агента

Этот файл для агента (Claude Code, Codex и другие), которого человек попросил поставить Telemost MP4. Говори с человеком на его языке, коротко и без терминов: он мог ни разу не открывать Терминал.

**Что ты ставишь.** Сторож для macOS: записи звонков программы Яндекс Телемоста для компьютера (webm) сами превращаются в mp4 в той же папке, webm уходит в корзину. Всё работает локально, без сети. Подробнее - `README.md`.

## Порядок

1. **Это Mac?** `uname -s` должен вернуть `Darwin`. Иначе скажи, что пока есть только версия для Mac, и остановись.
2. **Репозиторий.** Если его ещё нет на диске: `git clone https://github.com/nikolayetin/telemost-mp4.git ~/telemost-mp4`. Уже есть - `git -C ~/telemost-mp4 pull`. Дальше все команды - из этой папки.
3. **ffmpeg.** Проверь: `command -v ffmpeg; ls /opt/homebrew/bin/ffmpeg /usr/local/bin/ffmpeg 2>/dev/null`.
   - Есть - иди дальше.
   - Нет, но есть Homebrew (`command -v brew` или `/opt/homebrew/bin/brew`) - спроси человека, можно ли поставить ffmpeg, и после согласия выполни `brew install ffmpeg`.
   - Нет и Homebrew - дай ссылку https://brew.sh, объясни, что после установки Homebrew надо вернуться к тебе, и остановись.
4. **Два вопроса человеку** (одним сообщением, с ответом по умолчанию):
   - после перекодирования убирать webm в корзину или оставлять рядом с mp4? По умолчанию - в корзину.
   - перекодировать ли записи, которые уже лежат в папке Телемоста? По умолчанию - нет, только новые.
5. **Установка.** `zsh install.sh < /dev/null` с ключами по ответам: `--keep-webm` - оставлять webm, `--all` - перекодировать старые записи. Без терминала установщик вопросов не задаёт и отвечает на них «нет», поэтому всё, что решил человек, передавай ключами.
   - «Записи идут прямо в …» - в настройках Телемоста записи сохраняются в общую папку. Перескажи человеку: надо выбрать в настройках Телемоста отдельную папку для записей и запустить установку ещё раз.
   - «Телемост на этом Mac ещё ничего не записывал» - установщик взял стандартную папку «Документы/Телемост». Если человек знает, что в настройках Телемоста другая папка, повтори с `--dir <папка>`.
   - «Терминалу нет доступа к …» - macOS не пускает твой терминал к папке записей. Объясни, где разрешить (Системные настройки → Конфиденциальность и безопасность → Файлы и папки) и повтори.
   - Любая другая строка с «✗» - перескажи её человеку своими словами и предложи, что сделать.
6. **Разрешение macOS.** Предупреди человека: может появиться окно, что «Telemost MP4» просит доступ к папке «Документы». Нужно нажать «Разрешить», иначе сторож не увидит записи.
7. **Проверка.**
   - `launchctl print gui/$(id -u)/local.telemost-mp4 | grep -E "state =|last exit"` - агент загружен, последний выход 0.
   - `cat ~/Library/Logs/telemost-mp4.log` - строка «нет доступа» значит, что разрешение не дано: объясни, где его дать (Системные настройки → Конфиденциальность и безопасность → Файлы и папки → Telemost MP4), и повтори проверку.
   - Попроси человека сделать тестовую запись: зайти во встречу в программе Телемоста (можно одному), нажать «Записать на компьютер», подождать секунд 15 и остановить. Примерно через минуту в журнале должна появиться строка «готово … mp4». Покажи её человеку.

## Чего не делать

- Не запускай ничего через `sudo`: установщику права администратора не нужны.
- Не трогай файлы, настройки и журналы Телемоста и сами записи - только `install.sh`.
- Не правь `convert.sh` и `runner.swift` под человека: всё настраивается ключами `install.sh` (`--dir`, `--keep-webm`, `--trash-webm`, `--all`).
- Удалить всё: `zsh install.sh uninstall` - программа, агент и настройки уходят в корзину, доступ к папке отзывается, записи остаются.
