# Telemost MP4

**Записи Яндекс Телемоста сразу в mp4.** Нажал «Записать на компьютер», поговорил, остановил - и в папке лежит видео, которое открывается где угодно: в QuickTime, на айфоне, в Telegram, у коллеги на Windows.

## Зачем это

Программа Телемоста сохраняет запись звонка в webm. На Mac с ним неудобно:

- QuickTime его не открывает
- в iMovie и Final Cut его не вставишь, чтобы вырезать кусок
- коллеге, которому отправил запись, приходится объяснять, чем её открыть

Обычно после каждого звонка ищешь конвертер, перетаскиваешь файл, ждёшь, удаляешь исходник. Telemost MP4 делает это сам.

## Как это выглядит

1. В программе Телемоста нажимаешь «Записать на компьютер»
2. Разговариваешь
3. Останавливаешь запись, Телемост открывает папку с файлом
4. Через несколько минут рядом появляется mp4, webm уходит в корзину, приходит уведомление «Запись готова»

Час звонка перекодируется примерно за 3,5 минуты (замер на MacBook с M5).

## Батарею не трогает

- **Между звонками не работает вообще.** Ни программы в фоне, ни проверок по таймеру: macOS сама будит Telemost MP4, когда в папке записей появляется новый файл.
- **Во время звонка почти спит.** Раз в 20 секунд смотрит, растёт ли файл. Это одна команда оболочки, без запуска новых процессов.
- **Перекодирует видеоблок Mac** (VideoToolbox), сам скрипт идёт с низким приоритетом на экономичных ядрах.

## Установка

Понадобится:

- Mac и [программа Телемоста для компьютера](https://yandex.ru/support/telemost-desktop/)
- ffmpeg. Если его нет, установщик поставит его через [Homebrew](https://brew.sh): поставь Homebrew заранее
- инструменты разработчика Apple. Если их нет, macOS сама предложит их поставить

В Терминале:

```sh
git clone https://github.com/nikolayetin/telemost-mp4.git
cd telemost-mp4
zsh install.sh
```

Без git: на этой странице **Code → Download ZIP**, распакуй, в Терминале перейди в папку (`cd ~/Downloads/telemost-mp4-main`) и запусти `zsh install.sh`.

Установщик:

- найдёт ffmpeg или предложит поставить его через Homebrew
- найдёт папку, куда Телемост сохраняет записи (по журналу Телемоста; если записей ещё не было, возьмёт «Документы/Телемост»)
- соберёт маленькую программу «Telemost MP4» в `~/Applications`: macOS пускает к папке «Документы» только программы, поэтому сторож работает через неё
- спросит, перекодировать ли записи, которые уже лежат в папке

Если macOS спросит, пустить ли «Telemost MP4» к папке «Документы», нажми «Разрешить», иначе он не увидит записи.

## Настройки

| Что нужно | Команда |
|---|---|
| Оставлять webm рядом с mp4 | `zsh install.sh --keep-webm` |
| Снова убирать webm в корзину | `zsh install.sh --trash-webm` |
| Перекодировать старые записи без вопроса | `zsh install.sh --all` |
| Поменял папку записей в настройках Телемоста | `zsh install.sh` ещё раз |
| Указать папку записей вручную | `zsh install.sh --dir ~/Documents/Телемост` |
| Обновить | `git pull && zsh install.sh` |
| Удалить | `zsh install.sh uninstall` (всё уходит в корзину, доступ к папке отзывается, записи на месте) |

## Вопросы

**Записи куда-то отправляются?**
Нет. Всё происходит на твоём Mac. В сеть ходит только установка ffmpeg через Homebrew, сам Telemost MP4 сети не касается.

**Он тронет другие файлы в папке?**
Нет. Telemost MP4 берёт только те webm, про которые сам Телемост написал в своём журнале, что начал их записывать. Файлы, которые ты положил в папку сам, остаются как есть. А если в настройках Телемоста записи идут прямо в «Загрузки», «Документы» или на «Рабочий стол», установщик откажется и попросит выбрать отдельную папку.

**webm удалится, если что-то пойдёт не так?**
Нет. В корзину он уходит, только когда Телемост подтвердил, что запись закончилась без ошибки, mp4 не короче записи, а сам webm за время перекодирования никто не менял. Иначе webm остаётся на месте, а в журнале видно почему.

**Сколько места занимает mp4?**
5-10 МБ на минуту звонка: от 300 до 600 МБ за час, зависит от того, сколько движения в кадре.

**Телемост вылетел посреди звонка?**
Telemost MP4 перекодирует то, что успело записаться, а webm оставит: конец записи Телемост не подтвердил.

**Переименовал запись, пока она перекодировалась?**
mp4 получит новое имя.

**А записи из браузера?**
Пока нет: браузер сохраняет их в другое место. Telemost MP4 работает с программой Телемоста для компьютера.

**Не приходят уведомления?**
Они приходят от имени «Редактора скриптов»: проверь «Системные настройки → Уведомления → Редактор скриптов».

**Что-то не работает?**
Смотри журнал: `~/Library/Logs/telemost-mp4.log`. Нет доступа к папке - там будет строка «нет доступа» и путь в настройках macOS, где его дать.

## Доступ и безопасность

macOS пускает к папке «Документы» только программы, которым ты это разрешил. Поэтому сторож работает через маленькую программу «Telemost MP4», и разрешение получает она. Учти:

- macOS выдаёт доступ ко всей папке «Документы», а не только к папке записей
- скрипт сторожа, папка записей и путь к ffmpeg вшиты в программу. Если их поменять, macOS сбросит разрешение и спросит заново. Поэтому после обновления она может спросить ещё раз
- в корзину программа убирает только webm из папки записей, рядом с которым уже лежит mp4
- ffmpeg программа запускает из Homebrew. Тот, кто может подменить ffmpeg на твоём Mac, получит и этот доступ. Так устроен любой помощник, который вызывает внешние программы

Если не хочешь давать доступ к «Документам» вообще, выбери в настройках Телемоста папку записей вне их, например «Фильмы/Телемост», и запусти установку ещё раз. Тогда разрешение не понадобится.

## Как устроено

- `install.sh` - проверки, сборка программы, установка и настройки
- `convert.sh` - сторож: узнаёт запись по журналу Телемоста, ждёт её конца, перекодирует (`h264_videotoolbox` + AAC), проверяет длину mp4, убирает webm в корзину
- `runner.swift` - программа-запускалка: в неё вшиты скрипт и настройки, через неё macOS даёт сторожу доступ к папке записей, она же кладёт webm в корзину

Будит сторожа launchd-агент `local.telemost-mp4`, который следит за папкой записей. Список обработанных записей лежит в `~/Library/Application Support/telemost-mp4`.
